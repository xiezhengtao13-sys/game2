## 玩家身份

**底层船员。** 不是舰长，不是天选之人。玩家在远望号上做的是具体的工作，
接触到的是这艘船真实运转的机械部分。这让「巨型工业结构」不只是背景板，
而是玩家每天要面对的东西。

# 第一部分 · 远望号

## 一、设计理念

**一座能够横渡星海的工业化人类城市。**

远望号不是战舰，也不是豪华星际客轮。它由巨型承力结构、独立殖民模块、
旋转生活环、工业设施和深空推进系统共同组成，是一座移动的太空基础设施。

三条设计原则：

1. **长期生存优先于短期性能**
2. **可靠性优先于外观**
3. **模块化优先于结构完整性**

因此它看上去庞大、复杂，甚至有些笨重。

但笨重不等于落后。它拥有极其先进的能源、计算、材料和空间工程技术——
工业化外观只是因为设计者没有试图隐藏那些真正承担功能的机械结构。

## 二、整体外观

### 第一印象

全长约 **2,800 米**。从远处看不像军舰，更接近一座沿中央轴线展开的巨型轨道空间站。

- 一条笔直而粗壮的中央舰体
- 两侧分布六座大型殖民模块
- 两个巨大的旋转生活环环绕中央舰体缓缓运转
- 舰体尾部是庞大的推进与能源设施，大量散热翼向后半部分伸展
- 舰首是一组层层叠叠的圆形和锥台形防护结构

没有机翼，没有为空气动力学设计的流线外壳。

侧面看修长，主体分段感明显。正面看，中央舰体、生活环、殖民模块和外部桁架
共同形成复杂而基本对称的几何轮廓。当生活环旋转而主舰体保持稳定时，
整艘船呈现出独特的机械运动感。

外表面没有密集的照明和装饰。大部分区域是**灰白色、银灰色或深灰色**。
少数承担高温工作的部件采用深色耐热涂层；部分设备因长期受辐射、微小碎片撞击
和维护作业影响而存在轻微颜色差异。

远处看主体近似灰白，越靠近越能看见数以万计的面板、支架、管线和检修装置。

**这艘船的美感来自巨型工业结构本身。**

### 整体尺度

| 项目 | 设计尺寸 |
|---|---:|
| 舰体总长 | 2,800 米 |
| 中央舰体最大直径 | 180 米 |
| 常规状态最大宽度 | 约 640 米 |
| 散热设施完全展开宽度 | 约 1,200 米 |
| 生活环外径 | 440 米 |
| 生活环数量 | 2 |
| 大型殖民模块 | 6 个 |
| 设计休眠人数 | 12,408 人 |
| 标准清醒工作人员 | 约 300 人 |
| 常规满载质量 | 约 340 万吨 |

尺度差异必须被强调：

- 一艘约 100 米的小型航天器停靠在旁边，只相当于它的一件大型附属设备
- 一名穿舱外航天服的工程师站在生活环表面，显得异常渺小
- 内部某些工业车间的尺度甚至接近大型地面造船厂

## 三、舰体结构

**轴向主脊梁与六模块环绕式布局。** 舰首到舰尾分五个部分：

| 舰体位置 | 主要结构 |
|---|---|
| 0—300 米 | 前向防护盾与深空探测系统 |
| 300—950 米 | 指挥、通信及前部交通设施 |
| 950—1,800 米 | 前部殖民模块、生活环及中央设施 |
| 1,800—2,350 米 | 后部殖民模块与工业交通枢纽 |
| 2,350—2,800 米 | 主能源、推进及尾部工程设施 |

> 分区是沿纵轴计算的近似工程范围。生活环、外部桁架及部分殖民模块会跨越相邻分区。

### 中央主脊梁

最主要的承力结构，由多层复合材料桁架、纵向承力梁和大型密封压力舱组合而成。

外观上不是一根封闭圆柱：一部分由完整装甲包覆，另一部分直接暴露交错三角桁架
和设备管线。可见纵向粗壮结构梁、横向加强环，以及大量沿主脊梁布置的设备支架。

高度模块化：单个结构单元制造完成后由自动装配设备与相邻单元连接。
局部结构损伤可由维修机器人更换外部桁架和防护面板。
**但中央主要承力结构不具备简单拆卸能力**——它仍是整艘船最重要的结构基础。

### 主脊梁内部

内部**不是**一条贯穿全船的巨大走廊，而是多条相互独立的交通、能源和维修通道：

- 人员交通干线布置在中央区域
- 大型货运干线与其平行，但拥有独立的隔离舱门和应急系统
- 能源、数据和冷却管线分布于不同工程夹层，避免单次事故同时破坏全部关键系统

每隔一定距离设置一个大型交通节点，与各殖民模块通过密封连接廊桥相连。
在没有人工重力的区域，廊桥的地面、墙壁和顶部均布置辅助移动扶手。

## 四、舰首：深空防护结构

不是尖锐舰艏，而是一组由不同直径防护板组成的多层结构：

最前方是**圆形消融防护盾**，其后是若干层相互分离的复合材料防护板，
每层之间留有距离。整体呈宽大圆盘逐步收缩，最终连接中央舰体。

目的不是抵御传统武器，而是应对高速星际航行期间可能遭遇的**尘埃与微小碎片**。
最前端材料必须能承受极端撞击和局部高温。

因此**舰首防护盾表面没有任何窗户**，也不布置常规人员活动设施。

### 前向探测阵列

安装在防护结构后方的独立伸缩平台上，根据航行状态改变工作方式：

- 星际巡航期间：采用受保护的观测通道，配合提前释放的无人探测平台
- 进入恒星系、降低航速后：部分大型光学设备才会展开

舰首后方还有数量众多的小型设备舱，分别容纳姿态控制设备、防护系统控制器、
探测器维护机械以及备用防护材料。

从侧面看，舰首厚重紧凑，与中部庞大的生活环形成鲜明对比。

## 五、六大殖民模块

分前后两组、每组三座：

**前部三座**

- **L-1**：生态与农业模块
- **R-1**：生活与社会模块
- **U-1**：医疗与生物模块

**后部三座**

- **L-2**：工业与工程模块
- **R-2**：科研与探索模块
- **D-1**：建设与运输模块

> L、R、U、D 是沿用建造时期形成的模块编号，L 和 R 分别代表左、右主要接口，
> U 和 D 对应上、下辅助接口。

六个模块并非完全规则地构成圆环，而是根据**质量分布、散热需求和内部运输效率**布置。
前后三座模块之间具有一定周向偏移，以降低空间干涉，并为大型散热设施和外部机库预留空间。

### 共同外形

每座都是长度约 **400 米**的细长压力容器。主体近似圆柱形，
但外部安装大量附属结构，轮廓更接近经过复杂工程设计的轨道设施。

不是简单悬挂在主脊梁上：每座通过数根大型承力桁架与主舰体相连，
桁架之间设置辅助交通廊桥、能源管线和防护结构。
远处看仿佛由一组巨型机械支架固定在主舰体周围，近处看则相当复杂。

每座模块至少有**两条人员通道、一条大型货运连接通道和多条独立工程管线**。
主体外部由成千上万块可更换防护板构成，防护板之间有清晰分界线，
部分区域有明显检修门和机器人工作轨道。

### L-1 农业模块

外观相对**封闭**——农业设施不依赖直接接受恒星光照，
内部植物主要通过高效人工照明和精确控制的生态系统生长，
因此没必要设计巨大的透明玻璃外壳。

外部可安装若干大型冷却设备，以及维持环境稳定的独立供电系统。
内部则分布多层生态实验舱和水培设施。

全面运行时部分外部散热设备会产生较高热负荷，
使 **L-1 具有与其他模块不同的热辐射特征**。

### L-2 工业模块

机械感最强烈。外部安装数座大型机械臂，以及连接中央货运系统的工业运输轨道。
模块底部设置大型密封货舱门，打开后可向外部空间运输重型设备。

部分工业设施**直接位于真空环境**中——例如大型金属构件制造设备
不必全部安装在密封车间内。因此外部有大量开放式工业平台、机械支架和起重设备。

**这是六座殖民模块中外观最复杂的一座。**

### R-1 生活与社会模块

相对规整。外部防护板更加完整，内部包含大量密封公共空间、居住舱、
服务设施和环境循环设备，并通过中央交通系统与两个旋转生活环连接。

外部不需要大面积照明，只有少量交通节点、检修设施和应急指示灯。
**从远处看显得十分安静。**

## 六、双旋转生活环

远望号最容易辨认的外部特征。每个外径约 **440 米**。

环体不是简单圆管，而是沿圆周延伸的**多层环形建筑**。
横截面近似扁平椭圆形，局部采用矩形压力舱结构。
外部包裹多层防护材料，不同居住区域之间设置密封隔舱。

每个生活环与中央主舰体之间由大型辐条结构连接：
一部分辐条承担主要载荷，另一部分容纳人员交通、电力传输和环境循环设备。
通过大型轴承结构与中央枢纽连接。

**两座生活环反向旋转**，以降低对整船姿态控制的影响。

### 环内重力

旋转产生离心加速度模拟重力。直径 440 米、转速约 **1.35 rpm** 时，
环体外侧区域可形成约 **0.45g** 模拟重力。

比地球低，但足以使长期生活环境更接近人类习惯。
飞船内部某些关键工作区域还可使用局部人工重力设备——
所以生活环**不是**全船唯一拥有重力的空间。
但旋转模拟重力能耗更低，也不必长期依赖先进人工重力设备。

### 环内空间

不是一条单独走廊，沿圆周划分为不同的居住和公共活动区：

- 船员宿舍
- 公共餐饮区
- 运动中心
- 健身和医疗恢复设施
- 公共植物区
- 娱乐与文化设施
- 小型生活服务中心

环形道路沿内部延伸。由于半径较大，人在其中生活时不会像小型旋转空间站那样
强烈感受到地面弯曲，但在较长走廊中仍可观察到轻微曲率。

站在某些大型公共空间中，能看见远处的建筑结构逐渐沿环体弯曲。
**这是整艘远望号最具有未来感的室内场景之一。**

## 七、舰桥与指挥中心

**不设置在最前端**，而是位于中央舰体前部、受厚重结构保护的位置。
完全封闭，外部没有大面积透明舷窗。

双层布局：上层负责日常航行与舰船管理，下层是独立的战时指挥中心。

### 主舰桥内部

椭圆形大厅，长约 **35 米**，宽约 **25 米**，面积约 **700 平方米**。

空间中央是舰长指挥席。**不是高高在上的王座**，而是一套拥有完整信息访问权限的
独立工作站，位置略高于周围工作席，确保舰长能观察各工作区域。

大厅最前方是一套**大型弧形显示系统**：日常状态下显示前方星空和航行信息，
需要时可转换为立体导航图、战术态势图或复杂的工程状态图。

周围工作席按功能分区：导航、通信、动力、防务、科学和人员管理部门各有独立控制台。

**关键设计选择**：显示设备并非全部采用悬浮全息投影。
对于需要长时间稳定工作的操作席，依旧保留大量**实体按钮、固定显示屏和机械应急开关**。

> 远望号追求先进，但不完全依赖华丽的交互界面。

### 舰桥设计风格

- 主体：浅灰白色金属与深灰色设备面板
- 地面：低反光深色材料
- 工作席周围：柔和的线性照明
- 正常运行时不会出现过亮、影响视觉观察的灯光
- 主要光源来自顶部照明系统和大型信息显示区域
- 紧急状态下照明可切换为分区警示模式

**整座舰桥的气质应当是克制、理性和高度专业化的。**

## 八、中央医疗与休眠系统

12,408 人的休眠系统**不是**一个巨大的房间。所有休眠舱按模块**分散布置**，
每个休眠区域都有独立的环境维持设备、生命体征监测系统和应急维护通道。

休眠舱多层排列，每组安装在大型结构框架中。
维护机器人通过专用轨道在不同休眠舱之间移动。
每个休眠舱都有独立的状态显示面板。

休眠区域**不适合大量人员同时活动**，主要空间用于设备维护、医疗操作和应急转运。
真正的公共生活设施集中在生活模块和旋转生活环内。

### 中央医疗中心

设置于主舰体内部，负责舰船级紧急救治，拥有完全独立的医疗供电系统和生命支持设备。

主要空间：急救中心、手术室、重症监护区、医学诊断区、独立隔离病房、医疗设备维护区。

**外观应当相对朴素**：大量容易清洁的浅色材料，高度标准化的医疗设备接口。

## 九、能源与推进设施

后部结构完全不同于前部的指挥与生活区域，主要容纳聚变反应堆、燃料处理设备、
能源转换系统和大型推进设备。

### 聚变反应堆

两座主反应堆采用**物理隔离设计**，每座安装在独立防护结构中，
周围设置复杂的冷却管线和维护通道。大型能源转换设备安装在相邻工程舱中。

从外部观察，尾部反应堆区域具有明显的**环形结构**，
多组大型冷却管线沿舰体方向延伸。设备安装区域相对开放，
便于维修机器人与大型机械臂作业。

### 推进装置

多组大型聚变推进器，集中安装在尾部主承力结构上。
远处看呈现为由数个大型喷口组成的**推进阵列**，喷口周围分布大量磁约束设备和冷却设施。

**推进器不是始终持续点火。** 正常深空巡航期间大部分时间处于低功率或待机状态；
进行大规模轨道修正、恒星系内机动或其他需要较大推力的操作时才会逐步提高输出。

> **设定自洽约束**：远望号的近光速航行依赖启航和目的地预部署的外部能源与加减速设施。
> 舰载推进器主要承担无法完全依赖外部设施的航行任务。

### 散热翼

尾部能源和推进设施附近设置大量可展开散热翼。

**不是装饰性的巨大金属翅膀**，而是由大量高温辐射板、循环管线和支撑结构组成。
辐射板工作温度较高，表面采用特殊耐热材料。

需要大量散热时向外展开，完全展开后整船宽度可达约 **1,200 米**，
使尾部呈现出类似巨型机械羽翼的轮廓。

低功率巡航时部分散热翼可折叠或调整角度，
但**散热设备不能简单完全关闭**——即使在深空中，
反应堆、计算设施和人员生活区也会持续产生废热。

## 十、外部港口、维修平台与小型飞船

多处外部停靠设施，最重要的是中央舰体下部的**大型交通枢纽**，
可供多艘小型飞船同时停靠。

装卸区由密封机库、外部停靠平台、机械臂和人员转运通道组成。
小型飞船通过标准化接口与远望号连接；
大型货运设备由自动运输系统直接送往工业模块和建设模块。

此外还有分布在舰体不同位置的小型维修气闸，主要供维修机器人和舱外工程人员使用。

**对于这样一艘大型飞船，外部维修不能完全依靠人员出舱。**
大量维护任务由沿舰体专用轨道运行的工程机器人承担。
因此靠近远望号时，经常可以看见大量小型机器人沿舰体表面缓慢移动，
检查防护面板、维护散热设施并修复局部结构损伤。

这些机械活动共同构成了远望号外部环境的一部分。

## 十一、内部装修与空间语言

内部设计应避免两个极端：

- **不应该**像现代军舰那样到处充满裸露管道与狭窄走廊
- **也不应该**像豪华客轮那样每个空间都有宽敞大厅和复杂装饰

**不同工作区应当具有明确的空间语言。**

| 区域 | 主要材料与色彩 | 空间特点 |
|---|---|---|
| 指挥区 | 灰白色金属、深色显示面板 | 整洁、专业、信息密集 |
| 生活区 | 浅木色、米白色、绿色植物 | 温暖、舒适 |
| 医疗区 | 浅灰白色、低反光材料 | 明亮、易清洁 |
| 工业区 | 深灰金属、黄色安全标识 | 高大、开放、机械化 |
| 科研区 | 白色与浅蓝灰色 | 模块化、高度标准化 |
| 工程区 | 裸露结构、管线及设备 | 紧凑、功能优先 |
| 舰长室 | 深灰、浅木色、暖白色 | 安静、克制、具有个人特色 |

这种分区设计可以让人**仅仅通过画面就判断自己位于远望号的哪个部分**。

尤其需要突出**不同尺度的差异**：

- 中央交通站和大型工业车间可以拥有数十米高的内部空间
- 生活模块采用更接近普通建筑的楼层高度
- 人员交通干线应比现代建筑的普通走廊宽敞，但也没必要设计得像城市广场

# 第二部分 · 舰长室

> 舰长室是游戏的**第一个场景**。

位于中央指挥区域内部，是一个相对安静的独立生活与工作空间。
总面积约 **120 平方米**，分为办公区、会客区、私人卧室、阅读区和生活设施。

整个空间呈现出一种**带有旧时代地球审美的未来主义风格**。

## 办公区

舰长的办公桌采用**低矮而宽大**的设计。桌面由深色复合材料制成，
边缘采用具有天然木材质感的装饰材料。桌面嵌入一套**可以完全关闭**的信息显示设备。

办公桌后方是一张**实体星图**：深色底板，星系坐标和航线通过细小的发光标记显示。
它不是覆盖整面墙壁的复杂全息影像，而是一件**兼具实用价值与装饰效果的长期航行设施**。

桌面上可以保留一些真正的**纸质文件**，以及少量个人物品。
这能让舰长室拥有生活气息，而不只是另一个控制中心。

## 星空观测墙

办公区一侧设置宽约 **6 米**的曲面显示墙，具有极高分辨率，
可以还原真实的恒星背景和外部观测画面。

**但其表面在关闭时并不是完全透明的**，更像一整面暗色玻璃墙。
当显示系统启动，整个墙面才会逐渐呈现出外部宇宙。

与普通科幻电影中夸张的全息显示不同，这里的图像应当**尽量克制**：

- 真实的太空背景大部分时间是**黑色**的
- 星星**不会**因为飞船正在移动就自动拉出大量明亮的光线
- 只有在切换到导航或科学观测模式后，系统才会叠加航线、目标标记和其他辅助信息

## 会客区

半开放式布局。一张低矮的**圆形会议桌**，配备**六张具有固定装置的座椅**
（固定装置是必要的：这里是飞船）。

周围放置实体书籍、少量绿色植物和旧地球艺术品。

墙面**不必**悬挂夸张的舰长肖像或军事徽章。
**一幅真正的地球摄影作品、一张历史地图，就足以成为这个空间最重要的装饰。**

## 卧室

面积约 **20 平方米**，以舒适性为优先。

- 墙面：暖灰色与浅木色搭配
- 床铺具备**失重固定装置**
- 床头设置**实体**紧急通信设备
- 室内拥有独立照明、温度和环境控制功能
- 配备一块较小的模拟舷窗，可以显示真实星空，也可以模拟地球上的自然环境

## 私人阅读区

整个舰长室中最具有个人特色的空间。

一侧是实体书架，另一侧是一套**离线**资料终端。不需要布置太多复杂设备：
一张舒适的阅读椅、一盏具有传统造型的阅读灯，以及一盆**真正的**绿色植物，
就足以建立一种与整艘飞船工业环境截然不同的氛围。

> 舰长室应当是整艘远望号内部少数能够暂时隔绝舰船工作环境的地方。
> 因此除必要的应急设施外，**不建议在这里设置大量始终运行的设备**。

# 第三部分 · 视觉设计核心原则

**第一，强调结构，而不是流线。**
让中央桁架、模块连接结构、生活环和散热设备真实地构成舰船轮廓。
不要用一层巨大的光滑外壳将它们全部覆盖。

**第二，强调工业规模。**
远望号的工业能力是它最重要的特点之一。
外部机库、机械臂、货运轨道和维修设施应当占据相当大的空间。

**第三，保持总体轮廓的明确性。**
尽管拥有大量复杂结构，从远处仍应能清楚辨认它的舰首、中央舰体、
两个生活环、六个殖民模块以及尾部推进设施。

**第四，避免过度军事化。**
应具有一定防御能力，但不要在舰体表面布满炮塔和导弹发射器。
**它首先是一座移动的殖民城市，其次才是一艘能够自卫的舰船。**

**第五，赋予它生活气息。**
不应只有舰桥、反应堆和工业车间。还应具有种植着地球植物的公共空间、
舒适的生活区、学校、运动设施、图书馆，以及能够真正使人长期居住的内部环境。

---

## 最终印象

**这不是一艘为了征服而建造的飞船。**

它是一座将人类的工业、知识、文化、生命和社会结构完整带入宇宙的**移动城市**。

# 附：这些设定怎么落到游戏里

| 设定 | 对玩法的意义 |
|---|---|
| 玩家是底层船员 | 视角从「工作中的人」出发，而不是从指挥席俯视 |
| 空间语言分区 | 每个场景应当一眼能认出属于船上哪个区域 |
| 尺度差异极大 | 场景之间应有强烈的空间对比，不要所有房间一样大 |
| 保留实体按钮与纸张 | 交互物件里应当有大量「非数字化」的东西 |
| 散热、废热、维护机器人 | 可以成为日常背景噪音与任务来源 |
| 生活环曲率 | 未来场景可用的独特视觉母题 |
| 移动城市而非战舰 | 冲突来源应当是生存与资源，而不是战争 |
