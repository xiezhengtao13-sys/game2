## 🕹️ 游戏操作指南

| 按键 / 控制 | 作用与功能 |
| :--- | :--- |
| **`W` / `A` / `S` / `D`** 或 **方向键** | 控制角色在 2,800 米全舰甲板内平滑行走巡视 |
| **`E` 键** | **互动**：靠近船员（舰长、工程师老周、医生等）或控制台设备弹出提示后按 `E` 对话与操作 |
| **`F` 键** 或 右下角 **`⛶ 全屏`** | 一键切换**浏览器全屏**，享受纯黑底色电影级沉浸感 |
| **`Z` 键** 或 右下角 **`🔍 视角`** | **视角变焦**：支持在 `1.00x`、`1.25x`、`1.50x` 之间自由缩放，大颗粒高精像素看得清清楚楚 |
| **`M` 键** 或 右下角 **`🗺️ 蓝图`** | **全息蓝图小地图**：实时查看全舰 7 大舱段分布、米级坐标（如 `📍 你在这里 (840m/2800m)`）与主线目标 |
| **`C` 键** | 快速呼叫全舰各舱段当班席位 |
| **`Q` 键** | 调出个人全息日志与任务备忘录 |

## 🌟 核心特色与技术亮点

1. **零外部资源 · 程序化 Web Audio 音频引擎**
   - 彻底摆脱 MP3/WAV 音频文件加载延迟，纯 Web Audio API 算法合成机械继电器按键声、终端打字哔哔声、双音调 LFO 警报、高压蒸汽泄放、爆破螺栓脱扣与离子引擎白噪音。
2. **全舰 2,800 米 7 大功能舱段连续拓扑**
   - 舰桥指挥区 ➔ 舰长起居室 ➔ 中央穿梭站 ➔ 穿梭机机库 ➔ 船员生活区 ➔ 医疗与休眠舱 ➔ 主聚变动力反应堆。
3. **中央磁浮快车网络**
   - 在中央穿梭站立柱上的交通调度终端交互，一键往返四大枢纽（舰桥、穿梭站、机库、动力舱），告别长跑疲倦。
4. **两章完整主线剧情推进**
   - **第一章 · 反应堆过热特级管损危机**：巡检 ➔ 警报爆发 ➔ 穿戴 EVA 重型防热服 ➔ 动力泵房手动泄压 ➔ 爆破抛弃损坏副散热器。
   - **第二章 · 恒星系探索与行星勘测**：驾驶「先驱者一号」离子穿梭机飞向「初辉」恒星系深空，安全降落「远境-IV」行星并开展地表 EVA 勘测。
5. **镜头物理微震与动态宇航服换装**
   - 爆炸、蒸汽冲击、穿梭机点火时镜头具有真实物理衰减震颤；换上宇航服后角色拥有高亮荧光青蓝透明面罩与陶瓷复合胸甲。

## 🛠️ 本地工程开发模式 (Local Development)

如果你想在本地基于源码进行修改与二次开发：

```bash
# 1. 克隆代码仓库
git clone https://github.com/xiezhengtao13-sys/game2.git

# 2. 进入前端目录并安装依赖
cd game2/agent_web_game_starter
npm install

# 3. 运行完整自动化测试套件
npm test

# 4. 启动本地实时热重载开发服务器
npm run dev
```
