# 小镇

一个俯视 2D 卡通风格的小镇生活模拟游戏。

你是刚搬来的新居民。在小镇里走走、和镇上的人聊聊天，
选一份自己喜欢的工作，为小镇做点事——然后看着它因为你的贡献慢慢变好。

## 跑起来

```bash
npm install
npm run dev
```

然后打开终端里给出的地址（默认 http://localhost:5173/）。

## 怎么玩

| 按键 | 作用 |
|---|---|
| **W A S D** | 走动 |
| **E** | 和面前的人或东西互动（提示气泡出现时） |
| **E / 空格** | 对话时翻到下一句 |
| **1** | 在告示板前选择工作 |

现在可以做的事：

- **逛逛小镇**：主街、十字路口、河上的桥、西南边的农田
- **和五个人聊天**：镇长、面包师、农夫、木匠、小孩——各有各的话
- **在告示板接活**：接下农夫的活，才能动那块地
- **种小麦**：走到田里按 E，翻土 → 播种 → 等它长熟 → 收割
- **磨面烤面包**：小麦拿去磨坊，面粉拿去烤炉
- **把面包交给镇长**：攒够三份贡献，镇上就会盖起一座集市

## 技术栈

- TypeScript（strict）
- Vite 7
- Canvas2D：游戏世界
- HTML/CSS：对话框与 HUD
- `node:test`：单元测试（为什么不是 Vitest，见 `docs/TESTING.md`）

## 开发原则

1. 游戏世界进 Canvas，不把角色做成 DOM；文字界面才用 DOM。
2. `src/game` 不直接依赖浏览器 API（所以纯逻辑都能在 Node 下测）。
3. `src/engine` 只实现当前游戏真正需要的能力，不提前造通用引擎。
4. 每个功能一个独立 Task，一个 Task 一次提交。
5. 改代码前先读 `docs/AGENT_RULES.md` 与 `TASKS.md`。

## 文档

- `TASKS.md` —— 路线图与每个任务的完成记录
- `docs/ART_PIPELINE.md` —— 美术管线：代码不硬编码任何图，替换美术不用改代码
- `docs/美术需求.md` —— 待出图的素材清单（含可直接使用的英文提示词）
- `docs/TESTING.md` —— 测试约定、沙箱限制、无头浏览器验证方法
- `docs/AGENT_RULES.md` —— 协作规则与 Definition of Done

## 常用命令

```bash
npm run dev        # 开发服务器
npm run build      # 类型检查 + 生产构建
npm test           # 单元测试
npm run art        # 重新生成占位美术
npm run art:brief  # 重新生成美术需求单
```
