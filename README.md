# 离散星海

一个俯视 2D 科幻游戏，背景是《离散星海》世界观下的**远望级深空殖民舰「远望号」**。

你是一名**底层船员**。远望号不是战舰，也不是豪华客轮——它是一座把人类的工业、
知识、文化、生命和社会结构一起带进宇宙的**移动城市**。你接触到的，是这艘船
真实运转的那部分机械。

## 跑起来

```bash
npm install
npm run dev
```

然后打开终端给出的地址（默认 http://localhost:5173/）。

## 当前进度

**第一个场景：舰长室。** 你已经可以走进去，并且把里面的东西都看一遍。

| 按键 | 作用 |
|---|---|
| **W A S D** | 走动 |
| **E** | 查看面前的东西（HUD 出现「XX · 按 E」时） |
| **E / 空格** | 看完一段后翻到下一句 |

舰长室里可以查看的东西包括：星空观测墙、舰长的办公桌、桌上的纸质文件、
实体星图、会客圆桌、床铺、绿植、书架、阅读椅、离线终端，以及墙上那幅地球照片。

## 技术栈

- TypeScript（strict）
- Vite 7
- Canvas2D：游戏世界
- HTML/CSS：对话框与 HUD
- `node:test`：单元测试（为什么不是 Vitest，见 `docs/TESTING.md`）

## 开发原则

1. 游戏世界进 Canvas，不把角色做成 DOM；文字界面才用 DOM。
2. `src/game` 不直接依赖浏览器 API（所以纯逻辑都能在 Node 下测）。
3. `src/engine` 只实现当前游戏真正需要的能力，不提前造通用引擎。
4. 每个功能一个独立 Task，一个 Task 一次提交。
5. **美术一律先占位**，每个素材在 manifest 里带详细文字描述，之后统一替换。
6. 改代码前先读 `docs/AGENT_RULES.md` 与 `TASKS.md`。

## 文档

- **`docs/设定集.md`** —— 世界观唯一事实来源。写剧情 / 美术 / 新场景前先读它
- `TASKS.md` —— 路线图与任务完成记录
- `docs/ART_PIPELINE.md` —— 美术管线：代码不硬编码任何图，替换美术不用改代码
- `docs/美术需求.md` —— 待出图的素材清单（含可直接使用的英文提示词）
- `docs/TESTING.md` —— 测试约定、沙箱限制、无头浏览器验证方法
- `docs/AGENT_RULES.md` —— 协作规则与 Definition of Done
